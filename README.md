Final Project Antia Lopez Bachelor of Computer Science

As a computer science major, sometimes I feel like my work in the future will not have a significant impact, but by connecting my computational skills with healthcare data, I can create an application that can help people. To that end, I decided to create this app with my grandparents in mind. I want to build a platform that makes their lives easier, one that’s intuitive and easy to use, helping them manage their health in an organized, stress-free way.

**Project Description:** 

CORE FEATURES:
1. Medication Search 
2. Interaction Detection Engine 
3. Drug Information Display 
4. User Profile 
5. Emergency Alerts

SECURITY AND ETHICS 
    HIPAA awareness 
    Data privacy 
    Medical disclaimer 
    Not replacing doctors

DATA 
1. Medication Search: RxNav - LHNCBC 
2. Interaction Detection Engine: DrugBank DDI Dataset 
3. Drug Information Display: openFDA

ARCHITECTURE OF THE PROJECT:
    Hybrid approach
    Local data: drug interaction and profiles data
    Remote API calls: medication information  


FULL PROJECT DEVELOPMENT STEPS: 
    Phase 1: Research and Planning 
    Phase 2: Database Design
    Phase 3: Environment Setup
    Phase 4: Database Development
    Phase 5: Backend Development 
    Phase 6: Frontend Development 
    Phase 7: Integration 
    Phase 8: Security 
    Phase 9: Testing
    Phase 10:  Deployment 
    Phase 11: Documentation 
    Phase 12: Final Presentation
